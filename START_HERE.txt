STEAMDECK JEWELS — START HERE
==============================

You do not need to understand the other files in this folder.

STEAM DECK / STEAMOS
--------------------
1. Switch to Desktop Mode.
2. Extract the entire SteamOS ZIP into your Downloads folder
   (not onto the microSD card).
3. Open the extracted folder in Dolphin, right-click inside it and choose
   "Open Terminal Here".
4. Type this and press Enter:

   bash setup-steamos.sh

5. Wait until it says "Setup complete." (The first setup needs internet.)
6. Close the terminal and open SteamDeck Jewels from the Desktop or application menu.

WINDOWS
-------
1. Install Python 3 from python.org if you do not have it (keep "py launcher" ticked).
2. Extract the entire Windows ZIP. Do not run setup from inside the ZIP preview.
3. Open the extracted folder and double-click setup-windows.bat.
4. Type 1 ("Install / Update from this download") and press Enter.
5. Wait until setup completes.
6. Open SteamDeck Jewels from the new Desktop shortcut.

LINUX
-----
1. Install Python and one Qt library:
     Ubuntu/Debian/Mint:  sudo apt install python3 python3-venv libxcb-cursor0
     Fedora:              sudo dnf install python3 xcb-util-cursor
     Arch:                sudo pacman -S python xcb-util-cursor
2. Extract the entire Linux ZIP into your home folder.
3. Open a terminal in the extracted folder and run:

   bash setup-linux.sh

4. Open SteamDeck Jewels from your application menu or Desktop.

FIRST TIME INSIDE THE APP
-------------------------
1. Choose Manage > Add Jewel Drive.
2. Enter your SD card's volume name and choose a gem.
3. Choose + Add Game.
4. Enter the game name and choose its jewel drive.
5. Pick a cover: search Steam (you choose from Steam's matches), enter a Steam AppID,
   or select your own 600x900 image.

NSFW games are hidden every time the app starts. Click the NSFW button to cycle
between Hidden, Shown and Only.

SteamGridDB is optional. To configure it, open:

   Help > Set Up SteamGridDB API Key

For more explanation, read docs/FIRST_RUN_GUIDE.md.

UPDATES
-------
Every time the app opens, it checks for a new version and asks whether you want
to update. Choose "Update Now" and the app closes, updates and reopens, or "Not Now"
to keep playing (an Update button stays in the top bar). You can also use
Help > Check for Updates at any time. Your games, drives, covers and API key are kept.

If the app ever won't start, run setup again from this folder to repair it.

PRIVACY
-------
The release starts empty. It contains no game list, covers, drive names, launch paths,
or API credentials. Your information is stored only on your device.
